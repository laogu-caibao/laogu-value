# 数据源（2026-09-29 实测修订）

## 当前 PE(TTM)/PB：东财 push2（主路径）

东财 `push2` 接口是当前估值数据的首选程序化来源：

```
https://push2.eastmoney.com/api/qt/stock/get?secid=1.600519&fields=f169,f170,f57,f58
```

- `secid`：`1.` + 上海代码 / `0.` + 深圳代码（如贵州茅台 `1.600519`）
- 关键字段：`f169` = 市盈率(TTM)，`f170` = 市净率，`f57`/`f58` = 证券代码/名称（用于校验）
- 带桌面端 UA 请求；返回 JSON，`data.f169/f170` 即数值

**局限**：部分网络环境返回 502（本沙箱已有先例，东财 push2 在 2026-09-29 的财经 skill 实测中备选化），502 时改用网页搜索兜底。

**备选（搜索兜底）**：搜索 `{公司} 市盈率 市净率`，取东方财富个股页（quote.eastmoney.com）、新浪财经、同花顺行情页的数值并注明来源与抓取时间。**注意**：搜索引擎常返回 moomoo 等站点数月前的页面快照（如快照显示"市盈率(静) 18.45"实为 3 个月前的数据），引用时必须核对页面标注的时间戳，超过 1 个月的快照必须注明数据时点，无法确认时效的按"未核验"处理。

> ⚠️ 新浪行情接口 `hq.sinajs.cn` **没有 PE/PB 字段**，不要在新浪上找估值数据。

## 历史 PE/PB 分位：无公开 API，只能靠搜索 + 研报交叉

**先说清楚局限**：目前没有稳定、免费、公开的历史 PE(TTM)/PB 时间序列 API（东财/新浪/腾讯的公开接口都不提供逐日历史估值序列；Wind/Choice 等终端数据不公开）。因此本 skill **不提供程序化的"分位百分比计算"**，分位结论只能来自已公开的区间描述，并遵守"两个独立来源交叉"规则。

**搜索模板**：
- `{公司} 历史市盈率 估值区间`
- `{公司} PE 分位`
- `{公司} 估值分析`（东方财富"估值分析"页常给出近 5 年 PE/PB 区间与当前分位描述）

**可交叉的来源类型**：
- 东方财富个股"估值分析"页（有近 5 年市盈率/市净率区间图与当前分位文字描述）
- 券商研报（东财研报中心/同花顺研报）中"估值"章节的区间描述，如"近 5 年 PE 中位数 XX、区间 XX-XX"
- 数据宝/同花顺 i 问财的估值分位口径（注明是其自有口径）

**规则**：同一区间数字必须有两个以上独立来源印证才可引用；研报要注明券商名与报告日期；实在拿不到则按 SKILL.md Workflow 第 3 步降级——只给当前值 + 行业对比，历史分位标"未核验"。

## 行业对比

- 搜索 `{公司} 同行业可比公司 市盈率` 或 `{公司} 所属行业 平均市盈率`
- 来源：东方财富行业板块页、同花顺行业对比、券商研报中的可比公司表
- 取 3-5 家主营高度重合的公司（或证监会同行业分类公司）的当前 PE/PB，逐条注明来源；行业平均值优先用东财/同花顺的行业口径并注明

## 兜底规则

接口失败或数据对不上时，一律用网页搜索补足并注明来源；补不到的统一标注"未核验"，不编造、不估算、不反推分位。
